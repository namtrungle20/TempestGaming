- rafce → React Arrow Function Component + Export Default
- rafc → React Arrow Function Component (không export)
- rfc → React Function Component (dùng function thường)
- rcc → React Class Component
- rconst → Tạo constructor trong class component


*cấu trúc thư mục:
tempest-gaming/
src/
├── libs/           # [CẤU HÌNH GỐC] 
│                   # Chứa axiosInstance, thiết lập interceptors (gắn token),
│                   # và các hàm helper thuần túy (utils.js).
│
├── services/       # [XỬ LÝ NGHIỆP VỤ - BUSINESS LOGIC]
│                   # Nơi thực hiện các cuộc gọi API cụ thể. 
│                   # Ví dụ: authService.js (xử lý login/logout), 
│                   # staffService.js (lấy danh sách, thêm/xóa nhân viên).
│                   # UI chỉ gọi hàm từ đây, không gọi trực tiếp Axios.
│
├── store/          # [KHO DỮ LIỆU TẠM THỜI]
│                   # Sử dụng Zustand để lưu trạng thái phiên làm việc (session).
│                   # Giúp các Component ở xa nhau vẫn dùng chung được dữ liệu.
│
├── page/           # [MÀN HÌNH CHÍNH]
│   ├── Auth/       # Trang SignIn, SignUp.
│   ├── Admin/      # Các trang quản trị (Dashboard, Staff Management).
│   └── Main/       # Trang chủ cho khách hàng.
│
├── layouts/        # [KHUNG BAO QUÁT]
│                   # AdminLayout (có Sidebar/Header admin) và UserLayout.
│
├── components/     # [LINH KIỆN TÁI SỬ DỤNG]
│   └── ui/         # Thư viện Shadcn đã cài đặt (Button, Card, Table...).
│
├── App.jsx         # [TỔNG TÀI ĐIỀU PHỐI] Quản lý Route và Phân quyền.
└── index.css       # [STYLE TOÀN CỤC] Background đường chân trời & biến CSS.
