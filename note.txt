Một số snippet hay dùng
- rafce → React Arrow Function Component + Export Default
- rafc → React Arrow Function Component (không export)
- rfc → React Function Component (dùng function thường)
- rcc → React Class Component
- rconst → Tạo constructor trong class component

│   ├── components/         # Các thành phần giao diện nhỏ

│   │   │   └── StaffTable.jsx
│   │   └── ui/             # "Đại bản doanh" của Shadcn/ui (Sinh ra từ npx)

│   │       ├── table.jsx
│   │       └── ...

│   ├── layouts/            # Khung bao quát (Wrapper) cho từng khu vực

│   │   └── AdminLayout.jsx # Bọc trang quản lý (có Sidebar chuyên dụng)
│   │
│   ├── pages/              # Các trang chính (Tập hợp từ các component)

│   │   │   ├── Login.jsx

│   │       └── StaffManagement.jsx
│   │
│   ├── hooks/              # Các Logic tùy chỉnh (useAuth, useLocalStorage)
